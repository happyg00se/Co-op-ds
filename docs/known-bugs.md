# Известные проблемы и ограничения — v0.2.0

## Установщик
* Проверен под Wine (6 сценариев) и юнит-тестами, но ещё ни разу не запускался на настоящей
  Windows с настоящим Steam. Первый реальный запуск — твой.
* Exe не подписан цифровой подписью, поэтому Windows SmartScreen и часть антивирусов
  предупреждают при первом запуске. Лечится только покупкой сертификата подписи кода
  (≈ 200–400 $/год) или накоплением репутации файла. Инструкция для игроков — в
  `docs/install-players.md`.
* Epic Games Store не ищется автоматически: игру нужно указать кнопкой «Выбрать…».
* Строка журнала внизу экрана установки — на английском (всё остальное — на русском/английском).
* В Wine (Linux/Steam Deck) окно работает, но появляется без плавного проявления и с меньшей
  частотой кадров; длинный путь к игре обрезается без многоточия.

## Не проверено на реальной игре
Вся Windows-часть (`version.dll`, `DSCoop.dll`) собрана кросс-компилятором и проверена только
на уровне компиляции/линковки и экспортов. Первый запуск на реальной DS DC — это шаг 1 гайда
по разведке; вероятные точки отказа:
1. Игра не импортирует `version.dll` → мод не грузится. Решение: сменить прокси-DLL (15 минут).
2. Denuvo/ранний старт: сигнатуры могут не находиться до распаковки — поэтому ждём окно + 5 с
   (`wait_extra_ms`). При проблемах увеличить.
3. `ImGui_ImplDX12`: если игра использует необычный формат back buffer или несколько
   swapchain'ов, оверлей может не инициализироваться — сеть при этом работает через
   `auto_host` / `auto_join_code` в `dscoop.json`.

## Известные дефекты
* Чтение позиции из рендер-потока — возможны «рваные» значения на границе кадра (torn read).
  Приемлемо для маркеров, будет заменено хуком игрового тика на этапе 2.
* `Loader::stop()` на `DLL_PROCESS_DETACH` выгружает плагины внутри DllMain — при аварийном
  завершении игры возможны ложные сообщения в логе. На нормальную работу не влияет.
* Релей: нет защиты от перебора кодов и флуда CREATE; комнаты анонимны. Для публичного
  сервера нужен rate limit (этап 6).
* NAT hole punching не реализован — весь трафик через релей (+1 RTT до сервера).
* `TickClock` не компенсирует дрейф часов хоста и гостя при RTT > 300 мс — экстраполяция
  может дёргать маркеры; тюнинг после реальных сессий.
* При отключении хоста гости узнают об этом по таймауту (10 с), а не мгновенно.
* В `version.dll` не проксируется недокументированный `GetFileVersionInfoByHandle`; игры его
  не используют, но если в логе будет `ERROR_PROC_NOT_FOUND` — добавить.
* Сборка MinGW даёт большие файлы (отладочная информация). Для релиза использовать
  `CMAKE_BUILD_TYPE=Release` или `strip`.

## Что сознательно отложено
* Полноценная модель второго Сэма (этап 2), груз/постройки/транспорт (3), бои (4), сюжет (5).
* Отключение официального онлайна внутри сессии (этап 5) — пока играем в оффлайн-режиме.
* Встраивание пункта в родное меню (этап 6) — сейчас ImGui-меню по `F9`.
