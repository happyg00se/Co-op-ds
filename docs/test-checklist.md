# Чек-лист ручного теста — v0.2.0

Отмечай ✅/❌ и прикладывай `dscoop/reports/report_*/` (кнопка «Собрать отчёт» в меню F9).

## A. Без игры (любая машина)
- [ ] `scripts/build-linux.sh` (или `cmake --preset linux-tools`): 3 теста ctest зелёные,
      `pytest` в `relay/` зелёный.
- [ ] `scripts/e2e-local.sh`: хост + 2 гостя через релей на localhost, в логах гостей видны
      позиции друг друга и чат `privet`.
- [ ] Тест-клиент хост на ПК A, гость на ПК B в одной LAN: `dscoop_testclient host` /
      `dscoop_testclient join --direct <ipA>:27015` — гость подключился, rtt < 10 мс.
- [ ] Релей на VPS: `host --relay vps:27000` выдаёт код; `join --code XXXXXX --relay vps:27000`
      с другого ПК (другая сеть / мобильный интернет) подключается, `desync=0`,
      `snap/s ≈ 28–30`.

## A2. Установщик (настоящая Windows + Steam)
- [ ] `DSCoopSetup.exe` запускается, SmartScreen обходится через «Подробнее → Выполнить».
- [ ] Окно само показывает папку игры и «Найдена: Death Stranding Director's Cut (Steam)».
- [ ] Ник подставлен из Steam, кириллица отображается нормально.
- [ ] «Установить» → «Готово!»; в папке игры есть `version.dll` и `dscoop\`, в
      `dscoop\backups\saves_install_*` — копия сохранений.
- [ ] DSCoop виден в «Параметры → Приложения»; удаление оттуда возвращает игру в исходное
      состояние, папка `dscoop` с копиями остаётся.
- [ ] При запущенной игре установщик отказывается и просит её закрыть.
- [ ] Игра в библиотеке на другом диске (D:\SteamLibrary) тоже находится.

## B. Загрузчик в игре (ПК с DS DC)
- [ ] После установки и запуска игры появился `dscoop/logs/dsloader.log`.
- [ ] В логе: `game exe`, `build_id`, `saves: backed up N folder(s)` (или понятная причина
      пропуска), `game window found`, `MinHook`.
- [ ] `dscoop/backups/saves_<дата>/` содержит копию папки сейвов.
- [ ] Игра запускается и работает не медленнее обычного (FPS в меню/в мире одинаковый с/без
      `version.dll`).
- [ ] Удаление `version.dll` полностью возвращает ванильную игру.

## C. Плагин / оверлей
- [ ] В главном меню игры поверх рисуется окно «DSCoop — Совместная игра»; `F9` прячет/показывает.
- [ ] При открытом меню мода мышь/клавиатура не уходят в игру; при закрытом — игра управляется
      нормально.
- [ ] Смена разрешения / fullscreen↔windowed не роняет игру (ResizeBuffers).
- [ ] `dscoop/logs/dscoop.log` содержит `ImGui DX12 overlay initialised`.
- [ ] Вкладка «Отладка» → «Собрать отчёт» создаёт `reports/report_<дата>/` с логами и
      `report.json`.

## D. Призраки (2 игрока)
- [ ] Игрок A: «Создать через релей» → виден код. Игрок B: вводит код → статус `connected`,
      в таблице игроков виден A и наоборот.
- [ ] Без оффсетов: на радаре у каждого движется точка другого (фейковая окружность, флаг
      `fake`).
- [ ] С оффсетами (после разведки шаг 2–3): позиция в таблице совпадает с реальной,
      точка на радаре соответствует направлению на напарника.
- [ ] С камерой (шаг 5): над напарником рисуется маркер с ником и дистанцией, не «уплывает»
      при повороте камеры.
- [ ] Чат доходит в обе стороны; выход гостя → `player left` у хоста; закрытие игры хоста →
      у гостя `host timeout`/`disconnected` без краша.
- [ ] 3–8 клиентов (можно тест-клиентами) в одной комнате — хост держит 30 снапшотов/с.

## E. Негатив
- [ ] Неверный код → ошибка «room not found» в событиях, игра жива.
- [ ] Релей недоступен → через 8 с «no answer from relay», можно повторить.
- [ ] Гость с другой версией мода → «rejected: DSCoop version differs».
